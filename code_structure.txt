-------------------------------------------------------------------------------------------
Inputs:
rgb: [3, H, W]
depth_c: [1, H, W]
normals: [3, H, W]
mask_inst: [1, H, W]
intrinsics: (fx, fy, cx, cy)

Image encoder (image_encoder.py):
In: rgb [3, H, W]
Out: [128, H/4, W/4] (stride 4)

Normal encoder (surface_normal_encoder.py):
In: normals [3, H, W]
Out: [normal_channels, H/4, W/4] (defaults to 128 in DenseFusion ctor)

Point building (depth_encoder.build_instance_points):
In: depth_c [1, H, W], mask_inst [1, H, W]
Out: points_xyz [N, 3], uv [N, 2] (N ≤ num_samples, default 4096)

Feature sampling (sample_2d_features, downsample=4):
rgb_pts: [N, 128] sampled from image features
normal_pts: [N, normal_channels] sampled from normal features

Point encoder (PointNetBackbone):
In: points_xyz [N, 3]
Out: point_feats [N, pointnet_channels] (defaults to 256 in DenseFusion)

Fusion:
Concatenate [point_feats, rgb_pts, normal_pts] → fused_features [N, 128 + normal_channels + pointnet_channels] (defaults to [N, 128 + 128 + 256] = [N, 512] in code, though comments still mention 704)

DenseFusion output (dense_fusion.py (line 98)):
fused_features [N, F]
points_xyz [1, N, 3] (adds batch dim)

Heads (network.py):
Input features are unsqueezed to [1, N, F]
PointSegHead: [1, N, F] → [1, N, num_classes]
OffsetHead: [1, N, F] → [1, N, num_keypoints, 3]

Losses:
├─ Keypoint Loss (BCE on heatmaps)
├─ Pose Loss (L1 on quaternion + translation)
└─ Total weighted loss
